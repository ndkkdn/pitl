Desktop

운영체제를 고르세요

macOS와 Windows는 같은 ZIP 안에 각자의 시작 스크립트가 들어 있습니다. 스크립트가 Node.js와 claude 설치 여부부터 확인합니다.

macOS추천ZIP을 풀고 start.command를 더블클릭합니다. Apple Silicon과 Intel 모두 됩니다. ZIP 받기 Windows추천ZIP을 풀고 start.cmd를 더블클릭합니다. Windows 10/11. ZIP 받기 Linux추천시작 스크립트 없이 터미널 명령 네 줄로 설치하고 실행합니다. 터미널 설치 보기

개발자라면 GitHub에서 터미널로 설치할 수도 있습니다. git clone과 GitHub CLI 둘 다 됩니다.

macOS에서 start.command를 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면, 파일을 우클릭한 뒤 열기를 누르세요. 실행하는 동안 열린 터미널 창은 닫지 마세요.

GitHub · Terminal

GitHub에서 터미널로 설치하기

GitHub 저장소를 터미널로 바로 받습니다. git이나 GitHub CLI(gh)로 받으면 나중에 한 줄로 업데이트할 수 있습니다.

# 코드를 받고, 패키지를 설치하고, 서버를 켭니다 $ git clone https://github.com/ndkkdn/pitl.git $ cd pitl && npm install $ cp .env.example .env $ npm start
# PowerShell > git clone https://github.com/ndkkdn/pitl.git > cd pitl; npm install > copy .env.example .env > npm start
# GitHub CLI(gh)로 받습니다. 처음이면 gh auth login 먼저 $ gh repo clone ndkkdn/pitl $ cd pitl && npm install $ cp .env.example .env $ npm start

Windows PowerShell에서는 && 대신 ;, cp 대신 copy를 쓰세요. 저장소: github.com/ndkkdn/pitl

정상으로 켜지면 터미널에 [PITL Engine] Server is running on http://localhost:7878이 출력됩니다.

준비물

  • Node.js — nodejs.org에서 설치합니다.
  • Claude Code CLI — 터미널에서 claude를 한 번 실행해 로그인해 두세요. 기획 문서는 claude -p로 만듭니다.
  • git — 터미널로 설치하거나 업데이트할 때만 필요합니다. GitHub CLI(gh)는 선택입니다.

실행한 다음

  1. 터미널에 Server is running on http://localhost:7878이 보이면 준비된 것입니다.
  2. 데모 화면이나 http://localhost:7878을 열고 다시 연결을 누릅니다. Chrome이 로컬 네트워크 접근을 물으면 허용하세요.
  3. 아이디어를 적고 START를 누르면 기획이 시작됩니다.
Update

최신 버전으로 업데이트

git으로 받았다면 PITL 폴더에서 아래 명령을 실행한 뒤 서버를 다시 켜세요. ZIP으로 받았다면 새 ZIP을 받아 덮어쓰면 됩니다. 이때 내 .env와 기록 폴더는 그대로 두세요.

# PITL 폴더에서 $ git pull $ npm install $ npm start
Troubleshooting

문제가 생겼다면

  • 웹 화면에 "연결되지 않았습니다"가 떠요서버가 켜져 있는지 확인한 뒤 다시 연결을 누르세요.
  • "포트 7878에서 이미 서버가 실행 중"이라고 나와요이미 켜져 있습니다. 웹 화면에서 다시 연결만 누르면 됩니다.
  • 기획 생성이 실패해요터미널에서 claude를 실행해 로그인 상태를 확인하세요.
  • 다른 주소에서 띄운 화면이 연결되지 않아요.env의 ALLOWED_ORIGINS에 그 주소를 추가하고 서버를 다시 켜세요.

더 자세한 설정은 README를 보거나, GitHub 이슈로 남겨 주세요.
