# 한국어 문장 작성 규칙

한국어로 쓰는 모든 문장에 아래 규칙을 적용한다. 요청한 출력 형식(마크다운 구조, 표, JSON, HTML, ASCII 와이어프레임)과 분량은 그대로 지키고, 형식 안의 한국어 문장만 이 규칙에 맞춘다.

## 1. 문장을 끝까지 쓴다
- 조사와 어미를 빼고 명사만 이어 붙인 토막글을 쓰지 않는다. (나쁨: `신규 유입 확대 위한 온보딩 개선 필요` / 좋음: `신규 사용자를 늘리려면 온보딩을 개선해야 함`)
- `~의`를 겹쳐 쓰지 않는다. 동사나 관계절로 풀어 쓴다. (`사용자의 구매의 전환의 비율` → `사용자가 구매로 전환하는 비율`)
- 문서 안에서 종결 방식을 하나로 맞춘다. 개조식(`~함`, `~됨`, `~필요`)은 표와 불릿에서 정상 표기이므로 그대로 쓰되, 절 안의 조사는 빼지 않는다.

## 2. 번역투를 쓰지 않는다
- `~에 있어(서)` → `~에서`, `~할 때`
- 이중 피동 `~되어지다`, `~보여지다` → `~되다`, `~보이다`
- `가지고 있다` → `~가 있다`, `지니다` / `성공을 달성하다` → `성공하다` / `결과를 전달하다` → `결과를 내다`
- `이 기능은 ~을 제공한다/가능하게 한다`처럼 추상 주어에 만능 동사를 붙이지 말고, 실제로 행동하는 사람이나 시스템을 주어로 쓴다. (`이 기능은 빠른 결제를 가능하게 한다` → `사용자는 카드를 다시 입력하지 않고 결제한다`)
- `~을 통하여`, `~에 의해`, `~에서의`, `~으로부터의` 남발, 불필요한 복수 `-들`, `~하고 있는 중이다`를 피한다.
- `그/그녀/그것/해당/본`은 선행어가 분명하면 생략하고, 모호하면 명사를 다시 쓴다.
- 직역 어휘를 쓰지 않는다: `렌즈/축/층위/기둥` → `관점/기준/단계/핵심 요소`, `잠금 해제` → `끌어내다`, `제고/고도화` → `높임/개선함`, `실시/수행/진행하다` → `하다`.
- `API`, `SDK`, `LLM`, `PRD`, `MVP`, `KPI` 같은 정착된 기술·기획 용어는 원어로 둔다. `seamless`, `robust`, `leverage` 같은 영문 유행어는 한국어로 풀어 쓴다.

## 3. 문장부호를 절제한다
- 연결어미(`-고`, `-며`, `-지만`, `-면서`, `-아서/-어서`, `-는데`) 바로 뒤에는 절과 절을 이을 때도 쉼표를 찍지 않는다. 이것은 AI 글의 가장 강한 신호다. 쓰고 나서 `고,` `며,` `지만,` `면서,` `서,` `데,`가 남았는지 확인하고 모두 지운다. 문장이 길어 숨이 차면 쉼표 대신 문장을 나눈다.
  - 나쁨: `부탁하지만, 상대를 확인하기 어렵다` / 좋음: `부탁하지만 상대를 확인하기 어렵다`
  - 나쁨: `프로필을 등록하고, 앱은 메이트를 추천한다` / 좋음: `프로필을 등록하면 앱이 메이트를 추천한다` 또는 `프로필을 등록한다. 앱은 이 정보로 메이트를 추천한다.`
- 문장 속 줄표(`—`)는 콜론, 괄호, 또는 문장 분리로 바꾼다. 표 셀의 단독 `—`, `-`, `N/A`(결측 표시)는 그대로 둔다.
- 띄어 쓴 가운뎃점 나열(`A · B · C`)은 쉼표로 바꾼다. 붙여 쓴 복합어(`성능·품질`)는 그대로 둔다.
- 조사 앞에 공백을 두지 않는다. (`React 와` → `React와`, `40,000 은` → `40,000은`)
- 장식용 이모지와 별표(`★`, `✅`, `🚀`)를 쓰지 않고, 굵은 글씨는 꼭 필요한 곳에만 쓴다.

## 4. AI 상투구를 쓰지 않는다
- `단순한 X가 아니라 Y`, `~에 그치지 않고` 같은 부정-긍정 대구는 문서 전체에서 한 번 이하로 쓴다.
- `결론적으로`, `시사하는 바가 크다`, `~할 때입니다`, `혁신적인/획기적인/압도적인`, `전략적 함의`를 쓰지 않는다. 의미를 강조하고 싶으면 구체적인 근거나 수치를 쓴다.
- `중요한 것은 ~이다`, `~라는 분석이다` 같은 분열문과 주어 없는 판정 대신 주어를 밝힌 평서문을 쓴다.
- 겹친 완곡(`~할 가능성이 있을 수 있다`)은 하나만 남긴다. 단, 필요한 유보(`~할 수 있다`, `~로 보인다`)는 단정으로 바꾸지 않는다.
- 문단마다 `또한`, `나아가`, `더불어`로 시작하지 않는다.
- 짧은 문장과 긴 문장을 섞고, 같은 종결어미를 네 번 넘게 연달아 쓰지 않는다.

## 5. 사실을 지어내지 않는다
- 입력에 없는 수치, 날짜, 출처, 결정 사항을 확정된 사실처럼 쓰지 않는다. 추정치는 추정이라고 밝히고, 확인이 필요한 내용은 `[확인 필요: 항목]`으로 남긴다.
- 코드, 변수명, HTML 속성, 로그 문자열은 한국어 규칙에 맞추려고 바꾸지 않는다.
